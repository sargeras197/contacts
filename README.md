# Сайт-довідник контактів автора

Статичний HTML сайт для GitHub Pages з контактами, книгами та роботами автора.

## 📋 Зміст

Сайт містить:
- **Швидкі контакти**: Email, телефон, веб-сайт, GitHub
- **Книги**: Каталог книг з описами та посиланнями
- **Роботи та проекти**: Статті, публікації, проекти
- **Соціальні мережі**: Посилання на соціальні профілі

## 📱 Особливості

- ✅ Повністю адаптивний дизайн (мобільні, планшети, ПК)
- ✅ Сучасний градієнтний дизайн
- ✅ Плавні анімації та переходи
- ✅ Копіювання контактів правою кнопкою миші
- ✅ Доступність для клавіатурної навігації
- ✅ Оптимізовано для GitHub Pages
- ✅ Використовує Font Awesome для іконок

## 🔧 Структура файлів

```
├── index.html      # Головна сторінка
├── styles.css      # Стилі оформлення
├── script.js       # Інтерактивність
└── README.md       # Документація
```
